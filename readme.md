# ООО «Арматурный цех»

Современный адаптивный корпоративный сайт компании **ООО «Арматурный цех»**.

Проект выполнен на чистом **HTML5**, **CSS3** и **JavaScript** без использования сторонних библиотек и сборщиков.

---

## Возможности

- ✅ Адаптивная верстка
- ✅ Современный промышленный дизайн
- ✅ Каталог продукции
- ✅ Блок услуг
- ✅ Информация о компании
- ✅ Этапы работы
- ✅ Кнопки «Написать нам в MAX» (пока без ссылки)
- ✅ Мобильное меню
- ✅ Плавная прокрутка страницы
- ✅ SEO-ready структура

# Связь через MAX

Формы и обработчики отправки удалены. Кнопки «Написать нам в MAX» пока отключены и не ведут на вымышленный номер.

Когда появится ссылка на контакт MAX, замените эти кнопки ссылками с сохранением CSS-классов и удалите пометки о скором появлении контакта.
